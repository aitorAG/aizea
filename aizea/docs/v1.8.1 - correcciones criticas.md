# v1.8.1 — Correcciones críticas

> **Fecha**: 2026-07-22

---

## Issues

### Issue 1: ChunkLoadError al crear curso
**Síntoma**: `Runtime ChunkLoadError: Loading chunk app/courses/[id]/materials/page failed`
**RCA**: Stale `.next` cache. El chunk JS fue reemplazado por una nueva compilación pero el cliente tiene la referencia antigua.
**Fix**: `rm -rf .next && pnpm dev --port 3100`

### Issue 2: Upload no funciona
**Síntoma**: Selecciono archivo → modal se cierra → no pasa nada
**RCA**: El XHR upload adapter puede estar roto. El `onload` handler no llama a los callbacks correctos.
**Fix**: Verificar `useMaterialAdapter.ts` — asegurar que `xhr.onload` resuelve la promesa y llama `onProgress(100)`.

### Issue 3: Links de cursos rotos
**Síntoma**: Click en curso → link roto. Refresh → funciona.
**RCA**: ChunkLoadError al navegar. Misma causa que Issue 1 (stale chunks).
**Fix**: Mismo que Issue 1.

### Issue 4: "Generar todo" falla en primera slide
**Síntoma**: Falla en slide 1, muestra error, la marca como lista (sin estarlo).
**RCA**: El handler de generación no respeta el estado de fallo. El `catch` marca `hasContent=true` aunque falló.
**Fix**: En el loop de generación, no marcar como `hasContent` si el retry agotó todos los intentos.

### Issue 5: Slide detail con HTML roto
**Síntoma**: `Cannot find module './vendor-chunks/mdast-util-to-hast@13.2.1.js'`
**RCA**: Dependencia de `react-markdown`/`rehype-katex` no resuelta en el bundle de Next.js. El módulo se usa en el slide detail pero Next.js no lo incluye en `serverExternalPackages`.
**Fix**: Añadir `mdast-util-to-hast` y `react-markdown` a `serverExternalPackages` en `next.config.ts`.

### Issue 6: PDF desborda también en altura
**Síntoma**: La slide desborda el A4 verticalmente.
**RCA**: El scale actual solo ajusta el ancho. La altura también necesita `overflow: hidden` en el contenedor `.slide-top`.
**Fix**: Añadir `max-height: 50%` y `overflow: hidden` en `.slide-top`. Ajustar scale para considerar también la altura.
