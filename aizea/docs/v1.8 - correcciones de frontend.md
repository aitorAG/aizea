# v1.8 — Correcciones de frontend

> **Fecha**: 2026-07-22
> **Estado**: Recopilación de issues de UX reportados por el usuario.

---

## 🔄 Curso y navegación

### Issue 1.1: La página de cursos no se actualiza al crear uno
**Síntoma**: Creo un curso → la lista no se actualiza automáticamente. Necesito recargar.

**Esperado**: Tras crear un curso, la lista debe refrescarse inmediatamente (optimistic update o router.refresh).

### Issue 1.2: Subida de material se queda eternamente cargando
**Síntoma**: Subo un PDF → el spinner se queda para siempre. Si recargo, el material sí está subido. El usuario no sabe si se subió o no.

**Esperado**: La barra de progreso debe completarse en tiempo real (XHR progress) y mostrar el archivo en la lista al terminar.

---

## 🌳 Árbol conceptual

### Issue 2.1: Primera generación del árbol no muestra banner
**Síntoma**: Genero el árbol por primera vez → se queda pensando, el banner NO aparece. Si recargo, entonces sí está.

**Esperado**: El banner de progreso debe aparecer inmediatamente al iniciar la generación.

### Issue 2.2: Banner dice "completado" pero sigue trabajando
**Síntoma**: El job se completa, el árbol se genera, pero el banner dice que sigue "jerarquizando". El estado del banner no refleja la realidad del job.

**Esperado**: El banner debe reflejar fielmente el estado del job. Usar RCA para encontrar por qué se desincroniza.

### Issue 2.3: Pantalla completa en blanco + Escape no funciona
**Síntoma**: 
- Al pulsar pantalla completa → pantalla completamente blanca
- Escape no sale de pantalla completa

**Esperado**: 
- Fullscreen muestra el árbol ocupando toda la pantalla con la toolbar visible
- Escape sale de fullscreen

---

## 📑 Gestión de diapositivas

### Issue 3.1: Scroll pasa por encima del header
**Síntoma**: En la vista de slides, al hacer scroll, el contenido pasa por encima de la barra de menú superior.

**Esperado**: El header debe estar por encima del contenido (z-index correcto, sticky).

### Issue 3.2: No se ve la jerarquía con líneas
**Síntoma**: Las slides no muestran líneas de conexión basadas en la jerarquía del árbol.

**Esperado**: Líneas verticales conectando slides padre-hijo, indentación progresiva.

### Issue 3.3: "Generar diapositivas" (con HTML) no genera HTML
**Síntoma**: El botón genera las slides pero sin el diseño HTML.

**Esperado**: El botón debe generar contenido + HTML para cada slide.

### Issue 3.4: Sin retry en slides fallidas
**Síntoma**: Si una slide falla al generarse, se pierde. No hay reintentos.

**Esperado**: Hasta 3 reintentos por slide. Si falla tras 3, marcarla en rojo en la lista.

---

## 📄 Exportación PDF

### Issue 4.1: La diapositiva desborda el A4
**Síntoma**: Al exportar PDF, la diapositiva renderizada desborda los límites del A4.

**Esperado**: La slide debe ajustarse al ancho del A4 (escalado correcto). El contenido de texto en la mitad inferior no debe desbordar.
